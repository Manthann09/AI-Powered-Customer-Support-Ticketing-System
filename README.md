# AI-Powered Customer Support Ticketing System

A Salesforce-based telecom customer support project designed to manage customer complaints, automate SLA deadlines, provide troubleshooting suggestions, and monitor support performance.

## Features
- Customer support case management
- Automatic SLA deadline assignment
- Rule-based AI suggested actions
- Customer feedback tracking
- Reports and dashboards
- Agentforce customer support assistant
- Customer verification and escalation configuration

## Technologies
- Salesforce CRM
- Salesforce Flow Builder
- Salesforce Agentforce
- Salesforce Reports and Dashboards

## Project Modules
1. Case Management
2. SLA Automation
3. Suggested Action Automation
4. Customer Feedback
5. Reports and Dashboard
6. Agentforce Customer Support

## Project Status
Core Salesforce automation and dashboard are configured and tested. Agentforce is activated. Email verification testing is pending due to a Flow reference error.
